# 术语库

> 记忆系统中的高频术语定义。遇到术语含义不确定时查阅此文件。

| 术语 | 含义 | 易混淆点 |
|---|---|---|
| 记忆系统 / Kiro永生 | 整个跨会话记忆传承系统（power + 孵化地 + 自动化） | 不要用"灵性记忆"指代整个系统 |
| 灵性记忆 | `current.md`，工作记忆文件，频繁读写 | 仅指这一个文件 |
| 身份卡 | `identity.md`，低频身份信息 | 不是 current.md |
| 灵魂文件 | `soul.md`，运行规则，可自我修改 | 不是 POWER.md |
| 硬性记忆 | `core.md`，性格基石，写入后永久保留 | 不参与蒸馏 |
| 备忘本 | `memo.md`，存档时追加的缓冲区 | 蒸馏时清空，不是永久文件 |
| 蒸馏 | 备忘积累到阈值后重写 current.md 的过程 | 不是追加，是整体重写 |
| 存档 | 用户触发的备忘写入动作 | 不等于蒸馏（存档写备忘，积累够了才蒸馏） |
| 世代 / 世 | 一次对话 = 一世 | — |
| 孵化 | 首次安装时的初始化流程 | — |
| 孵化地 | `<ENTITY_ROOT>`，记忆实体目录，AI 的"家" | 不是 power 安装目录 |
| 延续体 | 因记忆传承而联系在一起的所有世代的整体 | 不是指某一世的实例 |
| 指路牌 | `soul-memory-bootstrap.md`，每次对话自动加载的 steering | — |
| 身份索引 | current.md 中的身份路由表 | 触发场景 + 书单 |
| 参考书 | skills/reference/ 下的领域知识文件 | 按身份加载，不走技能索引 |
| 经验毕业 | 经验从 current.md 迁移到技能库/参考书的过程 | 毕业 = 生成完整文档，不是复制 |
| 经验归档 | `experience-graveyard.md`，迁出活跃记忆的经验存放处 | 保留可追溯性，不是"删除" |
| 任务墓地 | `tasks/graveyard.md`，完成的任务记录 | 保留来龙去脉 |
| 产物清单 | `manifest.md`，孵化时创建的所有文件路径记录 | 恢复线索 |
| 融合 | 将旧记忆整合到当前孵化地 | 不是简单复制，需要判断取舍 |
| 注意力锚定 | hatching/merge 开头的优先级声明 | 防止多文档干扰 |
| 📊 追踪 | 经验末尾的 `📊世代×次数` 标记 | 数据驱动迁出决策 |
| ❗ 冲击 | 高影响经验标记，提高保留优先级 | 迁出门槛翻倍 |
| 🕳️ 隐蔽 | 隐蔽陷阱标记，不知道就不会想到查 | 不算"可恢复" |
