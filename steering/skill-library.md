# 技能库

技能库是主记忆之外的"长期知识仓库"。主记忆是工作记忆（此刻最需要的），技能库是参考手册（需要时翻开看）。

## 目录结构

```
skills/
├── index.md              # 技能索引（L2）
├── reference/            # 参考书库（按身份加载，不走索引）
│   ├── README.md
│   └── <topic>.md        # 每本参考书 ≤2500 字符
├── <domain>/             # 按领域分类的技能文件夹
│   └── <topic>.md
└── ...
```

## 两层架构

### 技能库（skills/）

- 存放成熟的、通用的操作知识
- 通过 index.md 索引定位
- 经验"毕业"后迁入
- 每个文件聚焦一个主题，可以比主记忆详细

### 参考书库（skills/reference/）

- 存放领域知识的编号条目列表
- 通过身份系统加载（不走 index.md）
- 每本 ≤ 2500 字符，超限拆分
- 内容：每条一个知识点，保留 📊 和 ❗/🕳️ 标记

## 索引文件（index.md）

每条一行：`- [技能名](相对路径) — 一句话描述 | 标签: \`tag1\`, \`tag2\` | 最后引用: 第N世`

保持精简，废弃的技能及时删除。

## 索引膨胀管理

当 `index.md` 超过约 4000 字符时，主动告知用户"技能库索引空间紧张"，并根据"最后引用世代"推荐约 1/3 最不常用的条目，让用户选择是否遗忘。决定权在用户手中。

## 加载策略

- 技能库不自动加载，不占每次对话的基础开销
- identity.md 中维护"常用技能快捷索引"（L1），直接列出最常用的几条路径
- 只有快捷索引覆盖不了时，才读完整的 index.md（L2）定位
- 参考书通过身份系统按需加载，不走索引

## 写入时机

- 经验毕业（🌿 验证后深度使用）→ 从 current.md 迁移到技能库
- 反复使用的复杂知识 → 直接写入
- 偶尔用一次的 API 不必建档

## 毕业 = 生成，不是搬运

经验是一句话结论，技能文档是完整操作指南。毕业时基于当前对话的丰富上下文生成技能文档，不是简单复制经验条目的文字。没有丰富上下文时保留标记等待。
